⚡ UNIT 2 — CHEAT REVISION SHEET 1. MACHINE LEARNING ML = AI technique that learns patterns from data without explicitly programming every rule. Types ML ├── Supervised → Labelled data │ ├── Classification │ └── Regression │ ├── Unsupervised → Unlabelled data │ └── Reinforcement → Reward/Penalty 2. CLASSIFICATION vs REGRESSION Classification Regression Categorical output Numerical output Discrete Continuous Spam/Not Spam Salary Pass/Fail House Price Disease class Temperature Remember CLASS = Classification NUMBER = Regression 3. LINEAR REGRESSION Y = mX + c m = slope c = intercept X = input Y = output Residual Actual − Predicted Metrics MSE → Mean Squared Error RMSE → √MSE R² → Goodness of fit Lower MSE/RMSE = better R² closer to 1 = better 4. POLYNOMIAL REGRESSION Use when relationship is curved. Example: Y = c + mX + aX² Degree 1 → Straight line Degree 2 → Parabola Degree 3 → Complex curve Advantage: flexible Disadvantage: overfitting risk 5. KNN K = Number of neighbours Algorithm Store Data ↓ Choose K ↓ Calculate Distance ↓ Sort ↓ Choose K nearest ↓ Majority Vote ↓ Prediction Euclidean Distance d = √[(x₁−x₂)² + (y₁−y₂)²] Important Small K → sensitive to noise K=3/5 → generally more stable KNN is: Lazy Learning Because it doesn't build a model during training. 7. CONFUSION MATRIX PREDICTED +ve -ve ACTUAL +ve TP FN ACTUAL -ve FP TN Remember: TP: Correct Positive TN: Correct Negative FP: False alarm FN: Missed positive 9. CLASSIFICATION FORMULAS Accuracy (TP + TN) / Total Precision TP / (TP + FP) "When I said positive, how often was I correct?" Recall TP / (TP + FN) "Of all actual positives, how many did I catch?" F1 2PR / (P + R) Harmonic mean of Precision + Recall 10.
