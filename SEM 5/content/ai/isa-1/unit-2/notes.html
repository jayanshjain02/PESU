UNIT 2 — ARTIFICIAL INTELLIGENCE Machine Learning & Supervised Learning MODULE 1 — MACHINE LEARNING FUNDAMENTALS 1.1 Artificial Intelligence → Machine Learning AI aims to create machines capable of: * Reasoning * Learning * Problem solving * Perception * Decision making Traditional AI can use hard-coded rules, but writing rules for every possible situation becomes difficult as problems become complex. This led to Machine Learning (ML). Relationship Artificial Intelligence │ ↓ Machine Learning │ ↓ Learning from Data 1.2 Definition of Machine Learning Machine Learning is a branch/subset of AI that enables computers to learn from data and improve performance without being explicitly programmed. Key idea Traditional programming: Rules + Data ↓ Program ↓ Output Machine Learning: Data + Correct Examples ↓ Model ↓ Prediction 1.3 Why Machine Learning? ML enables systems to: 1. Learn from data 2. Adapt automatically 3. Improve with experience 4. Handle complex problems 5. Generalize to unseen data 1.4 Types of Machine Learning MACHINE LEARNING │ ┌───────────┼───────────┐ ↓ ↓ ↓ Supervised Unsupervised Reinforcement Learning Learning Learning │ ┌────┴────┐ ↓ ↓ Classification Regression Supervised Learning * Uses labelled data * Input + correct output are provided * Learns relationship between them * Predicts output for unseen data Example: Fruit features → Apple/Mango Unsupervised Learning * Uses unlabelled data * No predefined output * Finds hidden patterns/groups Reinforcement Learning * Agent interacts with environment * Receives rewards/penalties * Learns strategy to maximize total reward Examples: * Chess AI * Robot navigation * Self-driving simulation 1.5 ML Terminology Term Meaning Feature (X) Input variable Label/Target (Y) Output to predict Training Data Used to teach model Testing Data Used to test unseen data Model Learned mathematical/algorithmic structure Prediction Output produced for new data Example Weight | Color | Diameter | Fruit 160 | Red | 8 | Apple 180 | Yellow| 9 | Mango Features: Weight, Color, Diameter Label: Fruit MODULE 2 — SUPERVISED LEARNING & CLASSIFICATION 2.1 Supervised Learning Supervised learning trains a model using: Input Features (X) + Correct Output (Y) ↓ MODEL ↓ New X → Prediction The model learns the relationship between inputs and outputs. 2.2 Classification Classification is a supervised learning task where the output is a category/class label. Examples: Problem Output Spam detection Spam / Not Spam Animal classification Cat / Dog Disease diagnosis Positive / Negative Student result Pass / Fail Important Classification → Discrete/Categorical Output Example: Student → Pass Email → Spam Fruit → Apple 2.3 Regression Regression is supervised learning where output is a continuous numerical value. Examples: * House price * Temperature * Salary * Stock price * Rainfall Input → Model → Numerical Output House Size → Regression → ₹75,00,000 Classification vs Regression Classification Regression Category output Numerical output Discrete Continuous Spam/Not Spam House price Pass/Fail Salary Disease class Temperature 2.4 Dataset, Training & Testing Training Data Used to teach the model. Testing Data Used to determine how well the model performs on unseen data. Dataset │ ├──── Training Data → Learn │ └──── Testing Data → Evaluate 2.5 Overfitting & Underfitting Overfitting Model learns the training data too closely, including noise/mistakes. Training → Excellent Testing → Poor Underfitting Model is too simple and fails to learn the underlying pattern. Training → Poor Testing → Poor Easy memory Overfit = memorizes too much Underfit = learns too little MODULE 3 — LINEAR & POLYNOMIAL REGRESSION 3.1 Linear Regression Linear Regression predicts a continuous numerical value using a linear relationship. Equation Y = mX + c Where: * X = input * Y = predicted output * m = slope * c = intercept Meaning m: change in Y when X increases by 1. c: predicted Y when X = 0. 3.2 Example — Student Marks Suppose: 1 hour → 40 marks 2 hours → 50 marks 3 hours → 60 marks Every extra hour increases marks by 10. Therefore: m = 10 Using: Y = mX + c For X = 1, Y = 40: 40 = 10(1) + c c = 30 Therefore: Y = 10X + 30 For 6 hours: Y = 10(6) + 30 Y = 90 3.3 Best-Fit Line & Least Squares Real-world data doesn't perfectly lie on a straight line. Therefore Linear Regression finds the best-fit line. It uses the Least Squares Method. The method selects values of m and c that minimize the Sum of Squared Errors (SSE). Actual values ● ● ● ● -------------------- Best-fit line 3.4 Polynomial Regression Linear Regression works for linear/straight-line relationships. Polynomial Regression is used when the relationship is curved/nonlinear. General form For degree 2: Y = c + mX + aX² Degrees Degree Shape 1 Straight line 2 Parabola 3 More complex/S-shaped curve Polynomial Regression also uses Least Squares. Advantages * Fits curved relationships * More flexible Disadvantages * Risk of overfitting * Harder to interpret 3.5 Regression Evaluation Residual Residual = Actual − Predicted Also: y − ŷ Small residual → prediction close to actual. MSE Mean Squared Error Average of squared residuals. Smaller MSE → Better model RMSE RMSE = √MSE Lower RMSE → Better prediction R² R-Square / Coefficient of Determination Measures how well the model explains variation in the dependent variable. R² closer to 1 → better fit. MODULE 4 — SUPPORT VECTOR MACHINE (SVM) 4.1 Definition Support Vector Machine (SVM) is a supervised ML algorithm used for: * Classification * Regression Its main objective is to find the best hyperplane that separates classes while maximizing the margin. 4.2 Hyperplane, Margin & Support Vectors Hyperplane The decision boundary separating classes. Class A | Class B ● ● ● | ○ ○ ○ ● ● ● | ○ ○ ○ ↑ Hyperplane Margin Distance between the hyperplane and the closest points of each class. Support Vectors Data points closest to the hyperplane that influence the boundary. Support Hyperplane Support Vector │ Vector ● │ ○ <------ Margin -----><----- Margin ----> 4.3 SVM Algorithm Steps 1. Plot training data points. 2. Find possible separating hyperplanes. 3. Calculate margin for each. 4. Choose maximum-margin hyperplane. 5. Identify support vectors. 6. Store decision boundary as trained model. 4.4 Dimensions Features Boundary 1 feature Point/threshold 2 features Line 3 features Plane >3 features Hyperplane Main idea Maximum Margin A larger margin generally provides: * Better separation * Less confusion * Better generalization * Reduced overfitting 4.5 Multi-Class SVM SVM is fundamentally a binary classifier. For multiple classes, common approaches include: One-vs-One For 3 classes: Apple vs Mango Apple vs Orange Mango vs Orange One-vs-Rest Example: Apple vs Rest The PDF illustrates both approaches. Advantages * Good for high-dimensional data * Effective with clear separation * Good for small/medium datasets * Maximum-margin principle improves generalization Limitations * Computationally expensive for large datasets * Poor with noisy/overlapping data * Less interpretable * Training time increases with dataset/features MODULE 5 — K-NEAREST NEIGHBORS (KNN) 5.1 Definition & Principle K-Nearest Neighbors (KNN) is a supervised ML algorithm used for: * Classification * Regression It predicts a new point using its K closest training examples. KNN is called a Lazy Learning Algorithm because it does not construct a model during training. It stores training data and performs computation when prediction is required. 5.2 Working of KNN New Point │ ↓ Calculate distance from all training points │ ↓ Sort distances │ ↓ Select K nearest points │ ↓ Majority Vote │ ↓ Prediction For classification: Class with highest frequency among K neighbours wins. 5.3 KNN Algorithm Steps 1. Store training data. 2. Select value of K. 3. Calculate distance between new point and every training point. 4. Sort distances in ascending order. 5. Select first K points. 6. Count class occurrences. 7. Assign most frequent class. 8. Display prediction. 5.4 Euclidean Distance Common distance measure: d = √[(x₁−y₁)² + (x₂−y₂)² + ...] For two dimensions: d = √[(x₁−x₂)² + (y₁−y₂)²] Example Test point: (3,4) Training point: (0,0) Distance: √[(3−0)² + (4−0)²] = √(9+16) = √25 = 5 5.5 Choosing K Small K Example: K = 1 * Only nearest neighbour * Sensitive to noise * Can produce incorrect prediction Moderate K Example: K = 3 or 5 * Uses multiple neighbours * Majority voting * Generally more reliable/generalizes better KNN Pros * Simple * Easy to understand * Works for classification + regression * Good for small datasets * Few parameters KNN Cons * Slow for large datasets * High memory requirement * Sensitive to noisy data * Curse of dimensionality MODULE 6 — DECISION TREES 6.1 Definition A Decision Tree is a supervised ML algorithm that makes decisions by asking a sequence of questions about input features. It can perform: * Classification * Regression It represents decisions in a tree structure. 6.2 Components of Decision Tree ROOT NODE │ ┌──────┴──────┐ ↓ ↓ Decision Node Decision Node / \\ / \\ ↓ ↓ ↓ ↓ Leaf Leaf Leaf Leaf Root Node * Topmost node * Represents first/best feature * Only one root Decision/Internal Node * Contains condition/question * Splits data into subsets * Multiple decision nodes possible Leaf Node * Final prediction * Does not split further * Contains class/value 6.3 Decision Tree Construction Algorithm MUST MEMORIZE 1. Start with complete dataset. 2. Select most informative feature as root. 3. Create decision question. 4. Split dataset into subsets. 5. Check whether each subset contains one class. 6. If yes → create leaf. 7. Otherwise → repeat using remaining features. 8. Continue until leaves are pure or no further splitting is possible. Flow Dataset ↓ Select best feature ↓ Create Root ↓ Split Dataset ↓ Pure? ┌─┴─┐ Yes No ↓ ↓ Leaf Split again 6.4 Decision Tree Example — Disease Prediction Features: * Age * Fever * Cough * Sore throat * Contact Risk * Oxygen Target: COVID = Positive/Negative Example rule: Cough = Yes ↓ Contact Risk = High ↓ COVID = Positive The PDF's exercise demonstrates recursively splitting the data until branches become pure and then using held-out records for testing. 6.5 Decision Tree Advantages & Limitations Advantages * Simple * Easy to interpret * Tree diagram is easy to understand * Works with numerical and categorical data * Minimal preprocessing * Fast prediction after training Limitations * Sensitive to small dataset changes * Can overfit * Imbalanced data can affect performance * Large trees become difficult to interpret MODULE 7 — MODEL EVALUATION & ML WORKFLOW 7.1 Confusion Matrix A Confusion Matrix evaluates a classification model by comparing: Actual values vs Predicted values Binary Classification ![][image1] Four terms TP — True Positive Model correctly predicts positive. TN — True Negative Model correctly predicts negative. FP — False Positive Model predicts positive, but actual is negative. FN — False Negative Model predicts negative, but actual is positive. ## ## ## 7.2 Classification Metrics Accuracy Percentage of all predictions that are correct. Accuracy = (TP + TN) / (TP + TN + FP + FN) Precision Of all predicted positives, how many are actually positive? Precision = TP / (TP + FP) Recall Of all actual positives, how many were correctly identified? Recall = TP / (TP + FN) F1-Score Harmonic mean of Precision and Recall. F1 = 2 × Precision × Recall / (Precision + Recall) 7.3 Numerical Example Suppose: TP = 40 TN = 50 FP = 5 FN = 5 Total: 100 Accuracy (40 + 50) / 100 = 90/100 = 90% Precision 40/(40+5) = 40/45 ≈ 88.89% Recall 40/(40+5) = 40/45 ≈ 88.89% This is based on the email-spam exercise in the Unit 2 PDF. 7.4 Machine Learning Workflow MUST MEMORIZE Data Collection ↓ Data Preprocessing ↓ Feature Selection ↓ Model Selection ↓ Model Training ↓ Model Testing ↓ Prediction ↓ Model Evaluation ↓ Deployment Data Preprocessing Includes: * Remove duplicates * Handle missing values * Remove noisy/irrelevant data * Correct incorrect values * Convert categorical data to numerical Feature Selection Choose the most important input features. Example: Weight Color Diameter ## 7.5 Train-Test Split & Tools Example from the PDF: test_size = 0.30 means: 70% → Training 30% → Testing `random_state=42` ensures the random split remains reproducible.
