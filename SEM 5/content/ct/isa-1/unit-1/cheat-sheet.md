# **⚡ LAST-MINUTE CLOUD TECHNOLOGIES CHEAT SHEET**

## **Cloud Computing**

**Cloud \= Computing resources through Internet**

Examples:

* Servers  
* Storage  
* Databases  
* Software  
* Networking

---

## **Evolution**

**Mainframe → PC → Client-Server → Internet → Virtualization → Cloud**

---

## **Five NIST Characteristics**

### **O-B-R-R-M**

| Letter | Characteristic |
| ----- | ----- |
| O | On-Demand Self-Service |
| B | Broad Network Access |
| R | Resource Pooling |
| R | Rapid Elasticity |
| M | Measured Service |

---

## **Cloud Ecosystem**

Remember:

**Provider \+ Consumer \+ Developer \+ Broker \+ Auditor \+ Carrier**

* **Provider** → Provides cloud  
* **Consumer** → Uses cloud  
* **Developer** → Builds applications  
* **Broker** → Manages/optimizes services  
* **Auditor** → Checks security/compliance  
* **Carrier** → Provides network connectivity

---

## **Advantages**

**Cost \+ Scalability \+ Accessibility \+ Updates \+ Availability \+ Collaboration**

---

## **Disadvantages**

**Internet dependency \+ Security \+ Privacy \+ Limited control \+ Downtime \+ Vendor lock-in**

---

## **Security**

Remember:

**MFA \+ Strong Passwords \+ Encryption \+ Backups \+ Access Control \+ Monitoring**

---

# **☁️ Deployment Models**

### **Public**

**Many customers \+ provider-owned**

### **Private**

**One organization \+ dedicated**

### **Community**

**Similar organizations \+ shared**

### **Hybrid**

**Combination of clouds**

Memory:

> **Public \= Many**  
> **Private \= One**  
> **Community \= Similar group**  
> **Hybrid \= Combination**

---

# **🧑‍💻 Service Models**

### **IaaS**

**Infrastructure**

VMs \+ Storage \+ Networking

**High control**

Examples: AWS EC2, Azure VM

### **PaaS**

**Platform**

Development environment

**For developers**

Examples: Google App Engine

### **SaaS**

**Software**

Ready-to-use application

**For end users**

Examples: Google Workspace, Microsoft 365, Zoom

Memory:

> **IaaS → IT Team**  
> **PaaS → Developer**  
> **SaaS → End User**
